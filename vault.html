Set up encrypted credential

Paste the credential and choose a passphrase. Encryption runs entirely in this browser — neither value leaves your device.

Passphrase strength matters. The encrypted blob will live in a public GitHub repo, so anyone can attempt offline brute force. Use a long passphrase — four or more random words is good, dictionary single words are not.
Next steps to make this operational:
  1. Tap Copy blob above (or long-press the textarea → Select All → Copy).
  2. In Safari, open github.com/knechod/Claude_general/edit/main/vault.html
  3. Find the line const ENCRYPTED_PAT = ''; near the bottom of the file.
  4. Replace the empty '' with the copied blob, wrapped in single quotes: const ENCRYPTED_PAT = '<paste here>';
  5. Commit the change.
  6. Wait ~1 minute for GitHub Pages to rebuild, then reload this page — it will switch into decrypt mode automatically.
What's actually happening cryptographically?

Your passphrase is fed into PBKDF2-SHA256 with a random 16-byte salt and 600,000 iterations to derive a 256-bit AES key. The credential is then encrypted with AES-GCM using a random 12-byte IV. The output blob contains the salt, IV, and ciphertext (all base64), plus the KDF parameters so this file can decrypt itself later. Nothing is transmitted; all crypto runs in your browser via the Web Crypto API.
